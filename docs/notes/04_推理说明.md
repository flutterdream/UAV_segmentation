# 推理说明：如何从 sw_s12800.pth 还原

对应脚本：`infer_p0.py`（入口）+ `final_pipeline.py`（概率平均实现）

---

## 1. 加载什么

```python
payload = torch.load(ckpt, map_location="cpu", weights_only=False)
model = K.DeepKANSegSwin(K.NUM_CLASSES)
model.load_state_dict(payload["ema"], strict=True)   # ← 必须用 ema
model = model.to("cuda").eval().requires_grad_(False)
```

权重文件里有两套完整参数：

| 键 | 含义 | 是否用于输出 |
|---|---|---|
| `ema` | 训练中权重的指数滑动平均（decay 0.99） | **是** |
| `model` | 训练结束那一刻的即时权重 | 否 |

两者都包含完整编码器+DFR+解码器，加载错的**不会报错**，只会掉分。`infer_p0.py` 的 `--state` 默认就是 `ema`，不要改。

其余元信息：`iter=12800`、`val500_miou=0.7667573463241719`、`label_miou=0.6972141074778491`、`parent=r3.pth`。

## 2. 完整命令

```bash
cd /root/autodl-tmp/aic_semi/p0_scripts

python infer_p0.py \
  --ckpt /root/autodl-tmp/aic_semi/p0/sw_s12800.pth \
  --tag P0_sw12800 \
  --state ema
```

脚本行为：
1. 遍历 `official_data/test_3/images/*.png`（3594 张），按文件名排序；
2. 每张做 8 路概率平均（见下）；
3. `argmax(dim=1)` 取类别，并断言取值落在 1..8，越界直接抛错（防静默错包）；
4. 逐张存单通道 PNG（`Image.fromarray(uint8)`，PIL 模式 L）；
5. 打包 `predictions_P0_sw12800.zip`（`ZIP_STORED` 不压缩）。

## 3. 八路 TTA 的确切定义

来自 `final_pipeline.py` 的模块级常量，顺序不敏感（最终是算术平均），但**集合不能变**：

```python
PASSES = [(1.0, False), (1.0, True), (0.75, False), (0.75, True),
          (1.25, False), (1.25, True), (1.5, False), (0.5, False)]
#          (scale, hflip)
```

即：尺度 1.0 / 0.75 / 1.25 各配不翻转+水平翻转，再加 1.5（不翻）与 0.5（不翻），共 8 路。

**每一路的处理顺序（必须一致）**：

1. 若 `scale != 1.0`，用 **bilinear** 把原图缩放到 `(W·scale, H·scale)`
2. 若 `flip`，对图像做水平翻转 `image[:, ::-1]`
3. 归一化：ImageNet 均值/方差（`seg_swin.norm`）
4. 前向：`torch.autocast("cuda", float16)`，logits 若为 tuple/list 取第 0 项
5. 若 `scale != 1.0`，把 logits 用 **bilinear（align_corners=False）** 插值回 1024×1024
6. `softmax(dim=1)` → 概率
7. 若 `flip`，把概率张量在宽度维翻回来 `torch.flip(dims=(3,))`
8. 累加

**平均方式**：8 路概率**算术平均**（等权，无加权）→ `argmax`。

脚本里有两条断言：`torch.isfinite(averaged).all()` 且 `|sum(prob)-1|.max() <= 1e-5`，任一不满足直接抛错。

## 4. BN 校准：推理阶段没有

- `infer_p0.py` 与 `final_pipeline.py` 的推理路径全程 `model.eval()`，**不做任何 BatchNorm 统计重估**，也不注册 moments hook。
- 当前权重里的 BN `running_mean/running_var` 是**父权重构建时**就固化的：用 test_2 的 1300 张图统计，按 α=0.75 与原始 EMA 统计混合（含组间均值差方差项），只改 82 个 buffer，不改任何参数。详见 `05_复现链/REPRODUCE_FROM_SCRATCH_前序链.md` 第 9 条。
- `final_pipeline.py` 里确实有一个 `calibrate()` 函数和 `moments_hook`，但那是**复现父权重时用的**，输出推理不调用它。

> 若有人想在推理时再加一步 BN 重估，结果会变，且与 不再对应。这一点在我们自己的实验里也验证过：BN 池/α 的调整是负收益。

## 5. 后处理：没有

- 不做 CRF、不做连通域过滤、不做孔洞填充、不做形态学、不做类别偏置。
- `argmax` 之后只做一件事：**值域检查**（1..8），越界抛 `RuntimeError`。
- 因此 `predictions_P0_sw12800.zip` 里的每张图就是模型原始判决，没有人工修饰。

（背景知识：12 种后处理方案我们全部试过，全部为负，见训练配置文档末尾的证伪清单。）

## 6. 输出规格（合规检查项）

| 项 | 要求 | 本包实际 |
|---|---|---|
| 格式 | 单通道 PNG，非 RGB、非调色板 | PIL `mode="L"` ✓ |
| 尺寸 | 1024×1024 | ✓ |
| 像素值 | 0–8（类别 ID） | 1–8（无忽略类输出）✓ |
| 命名 | 与测试集文件名完全一致 | `test3_XXXX.png` ✓ |

自检命令（可独立于模型运行）：

```python
import zipfile, io, numpy as np
from PIL import Image
z = zipfile.ZipFile("predictions_P0_sw12800.zip")
ns = [n for n in z.namelist() if n.endswith(".png")]
assert len(ns) == 3594 and all("/" not in n for n in ns)
a = np.array(Image.open(io.BytesIO(z.read(ns[0]))))
assert a.shape == (1024, 1024) and a.dtype == np.uint8
assert a.min() >= 1 and a.max() <= 8
```

## 7. 复现的边界（必须如实写）

- 同一台机器、同一环境重跑，PNG 可以逐字节一致。
- **跨 GPU 型号 / 驱动 / torch 版本时，float16 累加顺序与 cuDNN 算法选择会变，PNG 不保证逐字节一致。** 判据应改为"重新上传评测，分数接近"，不能承诺哈希相同。
- 权重 SHA-256 必须一致；若不一致，说明权重文件被改过，此时结果无效。
