## 4. 复核脚本

```python
import hashlib
def sha(p):
    h = hashlib.sha256()
    with open(p, "rb") as f:
        for b in iter(lambda: f.read(1 << 22), b""):
            h.update(b)
    return h.hexdigest()

assert sha("sw_s12800.pth") == "873bb246c889012c9e873ce9c2df4a946a30e8cd116de383f8eb0967ced832b9"
assert sha("submission_P0_sw12800.zip") == "6a337e66218f402474bfe32c11331a26fe938556ec6cc1e41e5a4a4a1330d974"
```

1. `v1.pth`（400 步的试探性微调）未归档。它只用于确认流程可跑通，未归档、未参与后续链。
