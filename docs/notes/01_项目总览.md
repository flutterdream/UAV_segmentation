## 3. 最短还原路径（只验推理，不重训）

```bash
# 前提：官方测试集 test_3 的 3594 张图，放在 $ROOT/official_data/test_3/images
cd $ROOT/p0_scripts
python infer_p0.py --ckpt $ROOT/p0/sw_s12800.pth --tag P0_sw12800 --state ema
# 产出 $ROOT/submission_P0_sw12800.zip，SHA256 应为 6a337e66…（跨 GPU 可能不同，见下）
```

**注意**：跨 GPU / 驱动 / 库版本时，预测 PNG 不保证逐字节一致（float16 累加顺序、cuDNN 算法选择都会变）。判据是**重新评测分数接近**，不是文件哈希相同。这一点必须写进任何对外说明里。

## 4. 三个容易漏掉的点

1. **必须用 `payload["ema"]`，不是 `payload["model"]`。** 两者都存了完整权重，但 `model` 是训练结束时的即时权重，`ema` 是滑动平均——输出用的是后者。加载错会掉分且不报错。
2. **`PASSES` 的八个组合不能改。** 顺序不影响结果（最后是算术平均），但集合必须一致：三尺度 × 翻转 + 1.5 + 0.5。
3. **BN 统计已经在权重里了，推理时不要再校准。** α=0.75 的 test_2 统计混合是在重建父权重 `final.pth` 时做的；`infer_p0.py` 全程 `model.eval()`，不做任何 moments 更新。若有人"顺手"加一步 BN 重估，结果会变。
