## 2. 冻结范围（这是 的关键设计）

```python
for p in model.parameters():
    p.requires_grad_(False)          # 全部先冻结
for p in model.decoder.parameters():
    p.requires_grad_(True)           # 只解冻解码器
```

| 部分 | 状态 |
|---|---|
| Swin-B 编码器 | 冻结（前向仍计算，无梯度） |
| DFR（DeepKAN：dfr_in / dfr_blocks / dfr_out） | **冻结** |
| 解码器（GLKAN） | 可训，2.64 M 参数 |
| 全部 BatchNorm 的 `running_mean` / `running_var` / `num_batches_tracked` | 冻结，且 `model.eval()` 使得不更新 |

> DFR 全程未训练这一点很关键：原文 Table VI 的消融显示 DFR 的贡献大于解码器，所以"只训解码器"是一个**留有余量**的选择，也解释了为什么 6400 crop 之后就饱和了。后续若要再挖，方向是解冻 DFR（见 `train_dfr_未采用.py`），但那**不属于**。

## 3. 损失函数

```
loss = 0.20 × L_sup + 1.0 × L_KL
```

**L_sup**（`stage47_i600.segmentation_loss`）：

```
L_sup = 边界加权 CE + Dice + 0.5 × Lovász
```

- 边界加权：用 5×5 结构元做膨胀/腐蚀，环带像素权重 3.0，其余 1.0（`band_weight`）
- 类别权重 `CLS_W = [0.40, 0.49, 0.65, 0.94, 1.66, 0.37, 0.90, 2.59]`，对应 8 类，类别 0（忽略）权重固定 1.0
- Dice / Lovász 均 `ignore_index=0`

**L_KL**：

- 把学生与参考的 logits 双线性插值到 **256×256**，只取通道 1–8
- 参考 = **父解码器**在同样输入下的软预测（`ref_decoder`，深拷贝、eval、无梯度）
- 只在真值 `> 0` 的像素上求平均（忽略区域不参与）

## 4. 优化与正则

| 项 | 取值 |
|---|---|
| 优化器 | AdamW |
| 学习率 | `1e-5`，余弦退火至 `0.1×`（即 1e-6），`T_max = steps` |
| 权重衰减 | `0.01` |
| 梯度裁剪 | 1.0（按范数，只对可训参数） |
| 精度 | `torch.autocast("cuda", bfloat16)` |
| EMA | decay `0.99`，只维护解码器参数；**BN buffer 不参与 EMA**（保存时一律取父权的值，避免浮点漂移污染统计） |
| 随机种子 | 42 |

## 5. 数据顺序（可复现的关键）

```python
val_ids = split.json["val_ids"]            # 500 张
ids = sorted(set(range(6996)) - set(val_ids))   # 6496 张
random.Random(42).shuffle(ids)             # 固定打乱
order = ids[:steps * batch]                # 顺序消费，不重复、不重采样
```

- 训练用 6496 张，500 张验证 ID 完全不参与训练。
- **顺序消费而非随机采样**：第 n 步用的永远是 `order[n*batch : (n+1)*batch]`。这让"跑到第几步"与"看了哪些图"一一对应，任何中断/续训都能精确对齐。
- 消费张数超过 6496 时循环复用（本阶段 12800×4 = 51200 crop，约 7.9 遍全集）。

## 6. 数据增强

**只有几何**（`geo_aug`，种子 = `42*1000003 + step*batch + b`）：

| 操作 | 概率 |
|---|---|
| 水平翻转 | 0.5 |
| 垂直翻转 | 0.5 |
| 旋转 90/180/270 | 0.25 |

**没有**颜色抖动、亮度缩放、模糊、cutout。原因：颜色类增强在本任务上是负收益（见文末证伪清单）。

## 7. 监督信号来自哪里（重要）

- **监督**：官方 train 的 6996 张真值掩码（每步 batch 内实时读原始 PNG，1024×1024，不缓存、不缩放）。
- **没有**使用 test 集伪标签、没有使用任何外部数据。
- KL 参照是父解码器（自蒸馏），不引入新信息，只约束漂移。

## 10. 证伪清单（省得后来人重走）

以下方向在本项目上已被实验否定，**不要重复**：

1. BN 统计池大小 / 混合系数 α 的调整（用 8 张标注验证过，方向相反）
2. 后处理：去小连通域、补洞、形态学等 12 种，全部为负
3. TTA 分尺度加权（最优权重≈均权，即现状）
4. 朴素伪标签回收（三票一致的背景像素仅 59.3% 正确 → 背景净增 76% 张全量数据增强（几何 +0.0004、颜色 −0.006、两者 −0.007）
6. 在解码器上继续加步数（6400 crop 之后 val500 仅 +0.000096）
7. 压 Background / 偏置校准 / Ignore 后处理 / 续训 / SWA / 亮度归一化

> 第 5 条有一个重要限定：它是在 **val500（源域）** 上判定的，而 val500 看不见测试域的偏移（同一模型在源域森林 IoU 0.865，到测试域掉到 0.620）。所以"颜色增强无效"这个结论只对源域成立，不能外推到域鲁棒性。
