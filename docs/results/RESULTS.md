## 4　BN 统计混合扫描

BN 统计量用测试域统计做静态混合（源域统计 ← 测试域统计，混合系数 α）。
扫描结果见 `report_R*.json`：

| α | 混合系数 | 说明 |
|---|---|---|
| 0.75 | 基线 | 最终采用 |
| 0.55 | 减弱 | 未采用 |
| 0.90 | 增强 | 未采用 |
| 1.00 | 全替换 | 未采用 |

混合用的测试域统计（test_3）见 `bn_moments_test3.json`。
**推理时不要再做 BN 重估**——统计量已在权重里，重新校准会改变结果。

## 6　复现要点

1. **推理必须加载 `ema`**，不是 `model`（见 `weights/README.md`）。
2. **BN 统计量已在权重里**，推理全程 `model.eval()`，不做 moments 更新。
3. **8 路概率平均是单模型多视图**，不是模型集成。
4. **评测口径**：500 张验证集，1024² 原生分辨率，单次前向，argmax，
   忽略类（像素值 0）不计入统计。验证集 ID 见 `data/val_ids.json`。

```bash
python evaluate.py --ckpt weights/best_model.pth \
                   --images data/train/images --masks data/train/masks \
                   --val-ids data/val_ids.json
```
