## 0. 本文件的定位

前序全链（教师链、Swin/KAN 链、BN 统计混合）见 `REPRODUCE_FROM_SCRATCH.md`。
本文件描述在该链终点 `ckpt_kan_s2_i600_c1_alpha075_20261003.pth` **之上追加的四段"冻结编码器、仅训解码器"微调**，以及最终推理与打包。

四段微调带来，且不改变编码器、不引入任何外部数据、不做模型集成——推理时始终是单一模型的多视图概率平均。

## 1. 输入与前置条件

| 项目 | 内容 |
|---|---|
| 父权重 R0 | `ckpt_kan_s2_i600_c1_alpha075_20261003.pth`（随包提供） |
| R0 指纹 | SHA256 `60c499b9d860f2dd71ef964f047d4dbeed47a3b724f75f8a0b59a78bcf46952d` |
| 训练数据 | 官方 train 6996 张 1024×1024；排除 `split.json` 中 500 个 val id，余 **6496 张** |
| 验证数据 | 同 500 个 val id（源域诊断，不作选型唯一依据） |
| 标注闸门 | 8 张人工标注 test-3 真值，**仅作崩溃闸门**（低于 0.68 即停止），不参与好坏排序 |

> 说明：这 8 张标注以 R0 预测为底稿，实测其排序与标注分反而最低）。因此它只用于发现"结构性崩塌"，不能用于在 0.02 量级之间选版本。选型依据是 500 张 val 的 mIoU。

## 2. 四段微调的统一协议

**全程冻结**：编码器、DFR 模块、以及**全部 BatchNorm 的 running 统计**（`running_mean` / `running_var` / `num_batches_tracked` 均不改动）。
**唯一可训**：解码器（2.64 M 参数）。

| 超参 | 取值 |
|---|---|
| 损失 | `0.20 · L_sup + 1.0 · L_KL` |
| `L_sup` | 边界加权 CE + Dice + 0.5·Lovasz |
| `L_KL` | 父解码器在 256×256 上的软预测，通道 1–8 |
| 优化器 | AdamW，lr `1e-5`，余弦退火至 0.1×，wd `0.01` |
| 精度 / 裁剪 | BF16 自动混合；梯度裁剪 1.0 |
| EMA | 0.99（导出时解码器 BN buffer 一律保留父值，避免 EMA 浮点漂移污染统计） |
| 数据顺序 | 6496 张按 `random.Random(42).shuffle` 固定打乱后**顺序消费** |
| 增强 | 仅几何：hflip p=0.5、vflip p=0.5、rot90 p=0.25 |
| 随机种子 | 42 |

**四段命令（可直接执行）**

```bash
# 第 1 段：400 张 → 6400 crop
python train_decoder.py --tag v2 --parent final.pth --steps 1600 --batch 4 --kl 1.0

# 第 2 段：12800 crop
python train_decoder.py --tag r2 --parent p0/v2.pth --steps 3200 --batch 4 --kl 1.0

# 第 3 段：25600 crop
python train_decoder.py --tag r3 --parent p0/r2.pth --steps 6400 --batch 4 --kl 1.0

# 第 4 段：51200 crop，并在四个步数点各存快照 + 评 val500
python train_decoder.py --tag sw --parent p0/r3.pth --steps 12800 --batch 4 --kl 1.0 \
       --snapshots 3200,6400,9600,12800
```

每段的父权重即该段的 KL 参照；脚本会自动取父模型的解码器作为参考，无需另行指定。

## 5. 推理与打包

```bash
python infer_p0.py --ckpt p0/sw_s12800.pth --tag P0_sw12800
```

- 单模型八路概率平均（与前序一致）：尺度 1.0 / 0.75 / 1.25 各叠加水平翻转，再加 1.5 与 0.5
- 各路先将 logits 双线性还原到 1024×1024，再 softmax、翻转回原向、概率平均，最后 argmax
- 输出 3594 张单通道 PNG，1024×1024，像素值 1–8，文件名与测试集一致，平铺打包为 zip

**这不是模型集成**：只有一套权重，六种视图属于同一模型的测试时增强。

## 6. 事前固定的质量门槛

1. 每一段的 val500 必须高于其父段，否则停止该链；
2. 每段的 8 张标注 mIoU 不得低于 **0.68**（崩溃闸门）；
3. 不满足条件则不进入推理、不产出预测包；不允许调阈值或换种子重试。

本次四段全部通过。标注 mIoU 逐段为 0.7279 → 0.7186 → 0.7102 → 0.7034 → 0.6972，单调下降但始终高于闸门——该下降是"离父模型越来越远"的自然结果，与。

## 8. 不能宣称的事项

- **单种子**：全部实验仅用 seed 42，未做重复实验，0.01 以内的差异不应视为结论。
- **漂移累积**：每段以"上一段"为 KL 参照，参考点随之移动，漂移不设绝对上界；标注闸门只是相关性监控，不是理论保证。
- **val500 的性质**：它是源域诊断指标，与点）只在同族模型内校准过，跨模型族不可外推。
- **可复现性边界**：跨 GPU / 系统 / 库版本存在数值差异，重训权重不会与归档逐字节一致；应以重新评测为准，不能把历史。
- **解码器容量**：本链只训练 2.64 M 参数，其余完全冻结；收益来自对该解码器在源域标注上的继续拟合，不代表编码器层面的改进。
