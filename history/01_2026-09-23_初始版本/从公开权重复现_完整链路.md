## 1. 链路总览

```
┌─ 起点 ────────────────────────────────────────────────────────────┐
│  公开 ImageNet Swin-B（timm: tu-swin_base_patch4_window7_224）      │
│  由 code/kan_swin.py:322-324 的 encoder_weights="imagenet" 自动下载 │
└───────────────────────────┬───────────────────────────────────────┘
                            │  阶段 A（scripts/00a_stage_a_base_model.sh）
                            │  「N 线」四步 —— 含根因修复
        ┌───────────────────┴───────────────────┐
        │ [A1] 基础模型 16k, crop512, --exclude-noise
        │      → code/ckpt_kannoise_i16000.pth          (val 0.7630)
        │ [A2] 伪标签生成（对 test1 跑 ms2）
        │      → pl_cache_noise/
        │ [A3] PL 自蒸馏微调, crop640, 4000it
        │      → code/ckpt_kan_noise_pl_i1000.pth       (一致率 0.6804)
        │ [A4] 队友蒸馏, crop640, 4000it
        │      → code/ckpt_kan_noise_dist_i4000.pth ★   (一致率 0.7586)
        └───────────────────┬───────────────────┘
                            │  阶段 B（scripts/00_reproduce_all.sh）
        ┌───────────────────┴───────────────────┐
        │ [B1] DACS 域自适应自训练
        │      warm=A4 产物, anchor=teammate_690801,
        │      crop1024 + --scale-up, batch8, 4000it
        │      → ckpt_kan_dacs_cw7_1024su_relaxbg_b8.pth
        │ [B2] 推理（ms2x 多尺度 TTA）
        │      → output_kan_dacs_cw7_1024su_relaxbg_b8.zip
        │ [B3] 输出前自检（格式 / 尺寸 / 像素值）
        └───────────────────────────────────────┘
                            │
┌─ 终点 ────────────────────────────────────────────────────────┐
│  output_test2_kan_b8.zip    1300 张 /└──────────────────────────────────────────────────────────────┘
```

**关于「N 线」**：项目早期发现训练集含疑似错标图、且训练图偏暗导致模型走「亮度捷径」
（训练暗图占 40.8% vs test1 48.6%）。A1 的 `--exclude-noise`（代码内置 30 张 ID 清单）
+ 管线内置暗化增广即为该修复；基础模型 val 由 0.7535 提升到 0.7630，
该增益经 PL→蒸馏→DACS 逐级传递。

## 2. 阶段 A：公开权重 → 基础模型

脚本：`scripts/00a_stage_a_base_model.sh`　配置：`configs/stage_a.env`

```bash
# 四步全跑
bash scripts/00a_stage_a_base_model.sh

# 或只跑某几步（第1步基础模型可先验证）
bash scripts/00a_stage_a_base_model.sh 1
bash scripts/00a_stage_a_base_model.sh 3 4
```

| 步骤 | 命令要点 | 产物 | 显存/耗时 |
|---|---|---|---|
| A1 | `kan_swin.py --train --exclude-noise --crop 512 --target-iters 16000` | `ckpt_kan_noise.pth`（全量）+ `ckpt_kannoise_i16000.pth`（EMA 快照） | crop512 显存需求低；**阶段 A 的最大耗时头** |
| A2 | `pl_gen.py --ckpt ckpt_kannoise_i16000.pth --cache pl_cache_noise` | `pl_cache_noise/`（pred+conf 压缩缓存） | 纯推理 |
| A3 | `kan_swin.py --train --pl --pl-tau 0.85 --pl-cache pl_cache_noise --warm-base ckpt_kannoise_i16000.pth --crop 640 --target-iters 4000 --restart-lr 0.25` | `ckpt_kan_noise_pl.pth` + `_i1000…i4000` 快照 | 峰值在 **i1000** |
| A4 | `kan_swin.py --train --distill --warm-dist ckpt_kan_noise_pl_i1000.pth --crop 640 --target-iters 4000 --restart-lr 0.25` | `ckpt_kan_noise_dist.pth` + `_i1000…i4000` 快照 | 峰值在 **i4000**（一致率单调升） |

**耗时参考**：完整的「N 线八步」（= 阶段 A 四步 + DACS 训练 + 推理）历史实测 **约 12h GPU**，
阶段 A 四步占其中大部分。若只想复现阶段 B（约 3.5h），见 §3 的 `stage-b` 模式。

**断点续训**：每段受 `--max-seconds`（默认 9000s）限制自动退出；**重跑同一条命令即从快照 resume**，
不会重复算。小显存机器按段跑即可。

**数据路径**（可用环境变量覆盖，见 README 3.4）：
`DATA_DIR`（训练图）/ `MASK_DIR`（训练标签）/ `TEST1_DIR`（阶段 A 的测试集，必须是 test1）
/ `TEACHER_DIR`（A4 的队友教师标签，会自动链接到 `code/teammate_best/`）

## 3. 阶段 B：基础模型 → 输出包

脚本：`scripts/00_reproduce_all.sh`　配置：`configs/best.env`

```bash
bash scripts/00_reproduce_all.sh            # 完整链路（A + B）
bash scripts/00_reproduce_all.sh stage-b    # 只跑阶段 B（需外部提供 WARM_CKPT）
bash scripts/00_reproduce_all.sh infer-only # 跳过训练，用已有 ckpt 直接推理
bash scripts/00_reproduce_all.sh check      # 只做环境与数据自检
```

| 步骤 | 命令要点 | 产物 |
|---|---|---|
| B1 | `dacs_train.py --train --warm <A4产物> --anchor <锚目录> --seed 7 --crop 1024 --scale-up --batch 8 --target-iters 4000 --max-seconds 14000 --ce-weights 0.40,… --boost 1.10,…` | `ckpt_kan_<TAG>.pth` + 快照 |
| B2 | `dacs_train.py --infer --ckpt <B1产物> --out <OUTDIR> --tta ms2x` | `<OUTDIR>.zip` |
| B3 | `check_output.py <zip>` | 7 项自检报告 |

**关键配置（与  一致，勿改）**：

| 项 | 值 | 说明 |
|---|---|---|
| `BATCH` | **8** | ★ 复现  的关键。队内实测 2→4→8 = →→；8→16 反转 68.59。峰值 ≈ 18.08GB 显存 |
| `CROP` + `SCALE_UP` | 1024 + `--scale-up` | 全图视野，本项目最大单项增益（+0.5230） |
| `CE_WEIGHTS` | `0.40,0.65,0.78,0.94,1.66,0.37,1.25,2.59` | 背景权重低谷点（Wave1 单调线扫描确定） |
| `BOOST` | `1.10,1.15,1.10,1.00,1.50,1.00,1.30,1.50` | 同上 |
| `SEED` | 7 | |
| `TTA` | `ms2x` | 仅最克制的多尺度档位为正增益（+0.0089） |

> ⚠️ **显存提示**：`batch 8` 实测峰值 ≈ 18.08GB。显存 <24GB 时请改 `BATCH=2`，
> 但那样复现的是 **test1 的 **，而不是 test2 的 。

## 5. 验证方法（三层，成本递增）

| 层 | 做什么 | 成本 | 状态 |
|---|---|---|---|
| ① 推理链 | 用 `…_relaxbg_b8_i4000.pth` 跑 test2 推理，与 `output_test2_kan_b8.zip` 逐像素对比 | ~1h | ✅ **已验证**：100 张采样，像素一致率 **99.9948%**（差异全在边界，属 GPU/算子级浮点差异） |
| ② 阶段 B | 从 `ckpt_kan_noise_dist_i4000.pth` 跑 batch8/4000it，与 B1 权重对比 | ~3.5h（需 ≥24GB） | 待验证（需租大显存实例） |
| ③ 阶段 A | 从公开权重重跑四步，与 A4 权重对比 | 最贵（约 12h 量级） | 待验证 |

**复现工具**：`code/cmp_dir_zip.py` —— 对比「推理输出目录」与「参考 zip」，
输出逐像素一致率与差异最大的图，用于层① 这类端到端比对。

**推理开销参考（本地 RTX 4050 6GB 实测）**：ms2x TTA 下 **2.97 s/张**，显存占用仅约 1.0GB。
⇒ test2（1300 张）约 64 min；**第三阶段合并集（3594 张）约 3 h**。

官方复现口径为「**使用赛事方提供的数据集能否复现性能**」，因此
**层 ① 是最高性价比的验证**；层 ②③ 可按算力选做。

## 7. 合规说明

- **预训练权重**：仅使用**学术领域公开**的 ImageNet Swin-B（timm 托管），符合任务
  「只能采用学术领域权重公开的预训练模型做微调，不能使用商业闭源模型」的要求。
- **数据**：训练与推理**仅使用赛事方提供的数据集**，未引入任何额外数据。
- **单模型**：最终输出为单个模型；`ms2x` 属同一模型的测试时增强（TTA），
  不属于多模型集成（model ensemble）。
- **队友资产**：阶段 A 的 [A4] 蒸馏使用同队队友提供的教师预测（`teammate_best`），
  阶段 B 的锚定回填使用队友预测（`teammate_690801`）。二者均为**训练期**使用的
  共享上游资产，不进入最终输出的模型结构；交付时已额外提供其来源说明。
  若赛事方对上游共享资产另有口径，按赛事方口径处理。
