## 两种正确的后续实验起点

1. **做严格单变量 Stage47 对照**：从 `stage47_retrain_package/inputs/ckpt_kan_segformer_distill_rebuilt_i2000.pth` 重新训练，固定原训练集、test1 教师锚、split、seed17、crop1024、真 batch8、源监督0.20、EMA0.999 和旧配置；只改变预注册的一项。原脚本 `stage47_retrain_package/scripts/run_stage47.sh` 会跑 0→1400 并保留 i600 等快照。需要 GPU，原实例 vGPU32GB 足够，历史峰值约18.6GB。
2. **做 i600 热启动探索**：从原始 i600 的 EMA 初始化新模型和**新**优化器。这是新实验，不能称作历史训练的无损续训。必须记录新学习率、步数、随机种子、父权重哈希和完整训练日志。

最终 BN0.25 权重只作推理或有明确说明的新实验初始化。它已引入 test2 无标签图像的 BN 统计，不应冒充尚未接触 test2 的训练快照。

## 数据和复现边界

- 队友需自行提供官方数据，文件数应为：train 图像6996、train 标签6996、test1 图像500、test2 图像1300。训练 ID 使用 seed123 划分；细节见 `stage47_retrain_package/inputs/split.json`。文件结构需为 `<数据根>/train/images`、`<数据根>/train/masks`、`<数据根>/test_1/images`、`<数据根>/test_2/images`。
- Stage47 源监督读取官方 train 标签；目标域使用 test1 图像和此严格链重新生成的 C6 教师硬锚。test2 **只用于最后的无标签 BN 统计与推理**，不提供人工标签。
- 血统：公开 Swin-B → 严格复现的 Swin/SegFormer 教师与 KAN 阶段 → 蒸馏 i2000 → Stage47 i600 → BN0.25 最终推理权重。上游每步详见 `evidence/` 和原始 `E:\复现` 工作区；**此优化包不替代完整从公开权重起跑的最终赛事复现材料**。
- 新实验必须分开记录：本地候选、生成输出包、已输出、真实。不要用本地500张结果推断 test2。已经试过的 i200 plain  和 i200 BN0.25 四路  不建议原样重投。
