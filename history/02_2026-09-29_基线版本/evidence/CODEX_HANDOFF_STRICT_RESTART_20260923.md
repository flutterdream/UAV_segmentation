## 5. 建议的从头复现顺序

1. 先完成输入清单和源码审核，确认训练进程不可能扫描归档、C盘或D盘的权重。

4. 训练前必须把配置、随机种子、数据划分、公开权重哈希和预期时长写入预注册文档。

6. 只有基座质量和伪标签置信度明显恢复后，才评估是否需要 32GB AutoDL。上云前先向用户说明显存、时长和预计费用。

## 6. 历史最高分训练思路（只作配方参考，禁止读取旧产物）

下一位 Codex 不得只做一个普通 KAN 基线就停止。已知的历史目标链是：

`Swin-B 公开学术权重`
→ `KAN-Swin-B 官方源域训练`
→ `test1 伪标签 PL`
→ `独立教师锚定/蒸馏`
→ `1024 整图 source-supervised 训练（47）`
→ `目标域 BN 统计更新（49）`
→ `test2 EMA + ms2 推理`
→ `S2-01 真实。

### 6.1 上游 KAN 与 PL

- 模型：Swin-B 编码器 + DFR + KAN 解码器，单模型。
- 源域基座：`crop=512`、`batch=2`、`target_iters=16000`、seed 42，验证划分 seed 123，保存 EMA。
- 编码器起点存在一处未完全确认的历史差异：源码支持先从公开权重训 Swin v4（512，12k），再训 v4.1（640，4k），最后用 v4.1 EMA 编码器初始化 KAN；简化复现脚本则允许 KAN 直接从公开权重训。直训实验的目标域置信度明显偏低，因此优先验证“v4→v4.1→KAN”完整血统。
- 基座 EMA 对 test1 做 `ms2` 八路推理，生成每像素 `pred + conf`。
- PL：阈值 `tau=0.85`、`crop=640`、`target_iters=4000`、`restart_lr=0.25`，历史选择 i2000，不是盲目选最后一步。
- 历史 PL-i2000 的500张官方验证 plain mIoU 记录约 `0.7388`；本次直训复现曾为 `0.7369`，但高置信像素仅 52.4%，说明不能只看 mIoU。
- 口径警告：历史 Swin v4 `0.745` 是 plain EMA 的 `n=100`；PL-i2000 `0.7388` 才是 `n=500`。两者模型和样本数都不同，不得混用。2026-09-23 新 v4 的 500 张 plain EMA 为 `0.7271`，在同一权重补评前100张之前，不得宣称其未复现历史 v4。

### 6.2 独立教师与锚定的缺口

- 历史记录使用 500 张独立教师硬标签做蒸馏，`crop=640`、`target_iters=4000`，历史选 i2000。
- 旧教师权重和旧锚预测均禁止使用。这是严格复现最大的缺口，不得伪装已解决。
- 若重建独立教师，必须也从公开学术权重+官方 train 重新训练，不得从旧教师续训。可以使用不同架构/随机种子制造独立性，但它只用于训练监督，最终推理仍只有一个 KAN 权重。
- 不得用同一个弱 KAN 给自己生成高覆盖率锚。这条路线已实测失败。

### 6.3 后半段 47 → 49 → S2-01

- 47：从当时的 i2000 状态暖启动，`crop=1024`、保留放大尺度增广（scale-up）、`batch=8`、seed 17、`target_iters=4000`、额外官方源标签分支权重 `source_supervised=0.20`。历史峰值显存约 19.15GB，需要 32GB 云端卡。
- 49：不做梯度训练，在47 EMA上使用目标域图像更新 BN 统计，更新系数 `0.25`。
- S2-01：对 test2 使用49 EMA + `ms2` 推理，生成 1300 张 PNG。该历史包的真实。
- 新复现只能复制以上配方思路和参数，不能读取历史47/49权重或历史 test2 预测。
- 47 之前必须设门槛：基座/独立锚的质量未恢复时，禁止上云重跑 47，否则只会重复上次 AutoDL 失败。
